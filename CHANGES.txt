## Fixes (each one reproduced on v16, then checked fixed on v17)
1. Dim text: --text-dim was a seven digit hex (#6070880), which browsers reject, so every "dim" caption showed at full brightness. Now #8090a8. The obvious intent, #607088, only reaches 3.3:1 contrast on the card panels, which is hard to read in the small pixel font; #8090a8 is about 5:1. See before-after-dim-text.png. Light theme unchanged.
2. Arven: tagged as Pokemon search and recovery; it searches an Item and a Tool. Now tagged Item search. No card requires either old tag, so grades do not change (test deck: 7.7 before and after). In Odds it now counts as fetching Rare Candy, not a Pokemon, so the with-search ceiling on the test deck went from 72% to 57%.
3. Prize browser badges disagreed with the score. It used its own looser matcher, so "Charizard" showed GUESSED on a Charizard ex that scored as a miss, and curly quote or energy button guesses that scored as hits showed MISSED. It now uses the score's own matches.
4. Prize browser image fallback broke on any card name with an apostrophe (Boss's Orders) and could run script from a crafted name. Replaced the inline handler with a safe function.
5. Timed mode: when the clock hit 0:00 with empty slots, cancelling the "Reveal anyway?" prompt froze the timer and play went on untimed. The time-up reveal now skips the prompt.
6. The red blinking timer carried over from a timed game into the next untimed game.
7. A leftover fragment of keyframe CSS swallowed the rule for the big timed-mode countdown, so it showed as small plain text in the corner. It is now the large gold centered clock it was styled as. See before-after-timed-countdown.png.
8. Weak Spots put card names into the page unescaped, so a pasted list could inject markup or script.
9. "Trending upward" compared raw scores across 4, 6 and 8 prize games (2/2 then 3/6 counted as up). Now compares percentages.
10. Header streak sorted games by day only, so same-day games across decks came out in deck order, not play order (en-GB dates also misparsed). New games now store a timestamp; older ones fall back to the date.
11. Progress dots stopped at 54, so in 4 prize mode the last two cards had no dot.
12. Thumbnail picker saved the primary image URL even when that 404ed and a fallback was showing, so the home card fell back to a blank. The results grid also never tried fallback art.
13. Duplicated decks lost their card data coverage report.
14. Grade read energy written as "Basic {R} Energy" as no type, flagging every attacker as having no energy. It now reads the symbol.
