# How well grades track tournament results

Results from matchups.json (2026-09-16 to 2026-11-15, newest set since 2026-11-06). Lists: the 130 fixed top lists in tests/grade-lists.json, so a new archetype shows up here only after the lists are refreshed. 1.00 means the grades rank archetypes exactly as their win rates do, 0 means no link.

- **All results (32 archetypes with 300+ games):** cards alone +0.15, grade as shown +0.84. The grade as shown uses these same results, so it is partly circular.
- **Since the newest set (28 archetypes with 100+ games):** cards alone +0.37, grade as shown +0.79.
