# How well grades track tournament results

Results from matchups.json (2026-09-16 to 2026-11-23, newest set since 2026-11-06). Lists: the 130 fixed top lists in tests/grade-lists.json, so a new archetype shows up here only after the lists are refreshed. 1.00 means the grades rank archetypes exactly as their win rates do, 0 means no link.

- **All results (35 archetypes with 300+ games):** cards alone +0.18, grade as shown +0.79. The grade as shown uses these same results, so it is partly circular.
- **Since the newest set (33 archetypes with 100+ games):** cards alone +0.23, grade as shown +0.69.
